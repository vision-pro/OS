# رؤية للإنتاج الفني | VISION Production

منصة ثنائية اللغة لشركة **رؤية للإنتاج الفني** في النجف، تجمع عرض الأعمال والخدمات والإنجازات مع لوحة إدارة محمية، حجوزات WhatsApp، إدارة وسائط سحابية، ومزامنة فيديوهات Instagram القابلة للاعتماد والنشر المنفصل.

> هذا المشروع **تطبيق كامل** يعتمد خادماً وقاعدة بيانات ومصادقة. لا يصلح نشره على GitHub Pages وحدها، لأن لوحة الإدارة والحجوزات والوسائط والمزامنة تحتاج بيئة خادم ومتغيرات سرية.

## الخصائص

يقدم الموقع واجهة عربية أولاً مع تحويل كامل للإنجليزية، وصفحات عرض عامة للأعمال والخدمات والإنجازات والعملاء والتواصل. تتضمن الصفحة الرئيسية عرضاً افتتاحياً خفيفاً، Carousel لشعارات العملاء المعتمدين، وحجزاً يحفظ الطلب ثم يفتح WhatsApp بالرقم المحدد.

تعتمد لوحة الإدارة على Google OAuth وصلاحية مسؤول. وهي تدير المشاريع والتصنيفات والخدمات والإنجازات والعملاء والشعارات والصفحات وSEO والطلبات والوسائط وفيديوهات Instagram. تُرفع ملفات الوسائط إلى تخزين S3؛ حد الفيديو هو 500 ميجابايت، والصور والمستندات 50 ميجابايت.

## التشغيل المحلي

يتطلب المشروع Node.js 22 أو أحدث وpnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

بعد تشغيل الخادم، افتح عنوان التطوير الذي يظهر في الطرفية. أضف قيم البيئة المطلوبة من مدير الأسرار في منصة الاستضافة أو من مسؤول المشروع؛ لا تضف ملف `.env` إلى Git، فهو مستبعد عمداً.

## متغيرات البيئة

استخدم الأسماء التالية فقط، واحفظ القيم في مدير الأسرار الخاص ببيئة الاستضافة. لا تضع قيماً حقيقية في المستودع أو في ملفات التوثيق.

| المتغير | الاستخدام |
| --- | --- |
| `DATABASE_URL` | اتصال قاعدة بيانات MySQL/TiDB |
| `JWT_SECRET` | توقيع جلسات المصادقة |
| `VITE_APP_ID` | معرّف تطبيق OAuth |
| `OAUTH_SERVER_URL` | خادم OAuth |
| `VITE_OAUTH_PORTAL_URL` | بوابة تسجيل الدخول في الواجهة |
| `ADMIN_EMAILS` | قائمة البريد المسموح له بالإدارة |
| `INSTAGRAM_GRAPH_ACCESS_TOKEN` | رمز Graph API لمزامنة فيديوهات Instagram |
| `BUILT_IN_FORGE_API_URL` | بوابة الخدمات المدمجة في بيئة الاستضافة |
| `BUILT_IN_FORGE_API_KEY` | مفتاح الخدمات المدمجة، للخادم فقط |
| `VITE_FRONTEND_FORGE_API_URL` | بوابة الخدمات المسموح بها للواجهة |
| `VITE_FRONTEND_FORGE_API_KEY` | مفتاح الواجهة المدمج |

راجع جدول المتغيرات أعلاه والمصادر التي تستدعيها `server/_core/env.ts` لمعرفة ما تحتاجه بيئة التشغيل. يحتاج رمز Instagram إلى تجديد أو رمز مستخدم نظام مستقر عند انتهاء الصلاحية.

## تجديد رمز Instagram ومراقبة المزامنة

يعمل الاستيراد الدوري كل ست ساعات فقط عندما تكون قيمة `INSTAGRAM_GRAPH_ACCESS_TOKEN` صالحة، ومتصلة بصفحة Facebook رقم `830116313518371` وحساب Instagram التجاري `17841470366415244`. لا تضع الرمز في Git أو لقطات الشاشة أو رسائل الدعم. إذا ظهر في لوحة الإدارة أو السجلات أن الرمز منتهي الصلاحية، استخدم أحد المسارين التاليين ثم استبدل السر في مدير الأسرار فقط.

| المسار | الاستخدام الملائم | النتيجة المتوقعة |
| --- | --- | --- |
| **رمز مستخدم طويل الأمد** | حل سريع تُجريه جهة لديها صلاحية إدارة التطبيق والصفحة والحساب | رمز صالح لمدة تقارب 60 يوماً، يحتاج إلى متابعة وتجديد قبل انتهاء الصلاحية |
| **رمز مستخدم نظام** | الحل التشغيلي المفضل للمزامنة المستمرة، بعد إعداد Business Manager وربط التطبيق والأصول | رمز أكثر استقراراً تحت إدارة النشاط التجاري والصلاحيات الممنوحة للتطبيق؛ راجع إعداداته ودورياً سلامة الوصول |

### المسار السريع: رمز مستخدم طويل الأمد

1. سجّل الدخول إلى [Meta for Developers](https://developers.facebook.com/) بالحساب الذي يدير التطبيق، صفحة Facebook، وحساب Instagram التجاري.
2. من **Graph API Explorer** اختر التطبيق الصحيح، ثم أنشئ رمز مستخدم يتضمن صلاحيات القراءة اللازمة للوسائط وإدارة الصفحات. يجب أن يوافق المسؤول على الصلاحيات وعلى ربط صفحة Facebook بحساب Instagram الاحترافي.
3. افحص الرمز عبر أداة **Access Token Debugger** في Meta وتأكد من ظهوره صالحاً ومن أنه يضم الصفحة والحساب المرتبطين.
4. بدّل الرمز قصير الأمد برمز طويل الأمد باستخدام مسار التبادل الرسمي في وثائق Meta. لا تضع قيمة الرمز في هذا الملف أو في أي مصدر عام.
5. حدّث `INSTAGRAM_GRAPH_ACCESS_TOKEN` في مدير أسرار بيئة الاستضافة، ثم أعد تشغيل الخدمة أو انتظر تنفيذ المزامنة التالية. تحقّق من ظهور وسائط جديدة كـ**مسودات** في لوحة الإدارة قبل اعتماد أي فيديو للنشر.

### المسار المفضل: رمز مستخدم نظام

1. افتح **Meta Business Settings** للنشاط الذي يملك الصفحة والحساب، ثم أنشئ مستخدم نظام مخصصاً للمزامنة باسم واضح، مثل `vision-instagram-sync`.
2. أضف تطبيق Meta إلى النشاط التجاري، وامنح مستخدم النظام أقل مجموعة صلاحيات تكفي لقراءة الحساب والصفحة والوسائط. اربط به صفحة Facebook وحساب Instagram التجاري، ولا تستخدم حساباً شخصياً غير مخصص للتشغيل اليومي.
3. أنشئ الرمز من إعدادات مستخدم النظام وفق آلية Meta الحالية، ثم افحصه في Access Token Debugger. احتفظ بتاريخ إنشائه، المالك التشغيلي، والصلاحيات الممنوحة في سجل داخلي غير عام.
4. احفظه حصراً في `INSTAGRAM_GRAPH_ACCESS_TOKEN` عبر مدير أسرار البيئة. بعد الاستبدال، راقب أول تشغيل مزامنة وتأكد من أن العناصر الجديدة تبقى مسودات إلى أن يعتمدها مسؤول الموقع.

> **تنبيه تشغيلي:** إذا فقد الرمز صلاحية الصفحة أو الحساب، أو غادر منشئه النشاط التجاري، أو تغيّرت صلاحيات التطبيق، تتوقف المزامنة حتى مع عدم انتهاء تاريخ الرمز. راجع إعدادات Business Manager والصلاحيات أولاً، ولا تمنح صلاحيات نشر أو إدارة لا يحتاجها مسار القراءة الحالي.

ضع تذكيراً داخلياً قبل 10 أيام من انتهاء أي رمز طويل الأمد، واحتفظ بمالك واضح لكل رمز. بعد كل استبدال، افحص آخر سجل للمهمة الدورية وتحقق من عنصر واحد على الأقل في قسم مسودات Instagram؛ لا تعتمد فيديوهات غير مراجعة تلقائياً.

## قاعدة البيانات والمخطط

يعرّف `drizzle/schema.ts` نماذج المحتوى والوسائط والحجوزات والعملاء والمستخدمين والإعدادات. عند تغيير المخطط، أنشئ الترحيل ثم راجعه قبل تطبيقه:

```bash
pnpm drizzle-kit generate
# راجع ملف SQL الناتج، ثم طبّقه في بيئة البيانات المقصودة
pnpm drizzle-kit migrate
```

لا تطبق ترحيلاً مدمراً على بيئة الإنتاج من دون نسخة احتياطية ومراجعة التبعيات.

## الفحص والاختبارات

```bash
pnpm check       # فحص TypeScript
pnpm test:ci     # اختبارات آمنة لبيئة CI بلا بيانات أو أسرار تشغيلية
pnpm test        # المجموعة الكاملة؛ قد تحتاج قاعدة بيانات ورمز Instagram صالحاً
pnpm build       # بناء الإنتاج
```

## الإدارة والنشر

ادخل إلى `/admin` باستخدام حساب Google المعيّن كمسؤول. ارفع الملفات من مكتبة الوسائط أولاً، ثم اربطها بالمحتوى واحفظه قبل استخدام زر النشر. لا تنشر شهادات أو تقييمات إلا إذا كانت حقيقية وموثقة.

يبقى النشر المستضاف الحالي هو المسار المتوافق مع الخادم وقاعدة البيانات. إن رغبت في استضافة خارجية، انقل متغيرات البيئة وقاعدة البيانات وS3 وOAuth والمهمة الدورية بصورة آمنة؛ لا تعتمد على GitHub Pages لتشغيل واجهات الإدارة أو API أو قاعدة البيانات.
